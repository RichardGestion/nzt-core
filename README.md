# ⚡ NZT-CORE
**Sistema Avanzado de Evaluación Intelectual Cognitiva — v4.8.0**

Panel de control mental inspirado en *Limitless (Sin Límites)*: mide y maximiza
la capacidad cerebral mediante trivias de nivel universitario (Ivy League)
organizadas en 19 lóbulos de conocimiento con desbloqueo semanal progresivo.

## 🧠 Características
- **Módulo A** — Inyección de código de acceso NZT con sesión persistente.
- **Módulo B** — Medidor circular de uso cerebral + 19 redes neuronales.
- **Módulo C** — Modo Enfoque: temporizador, dopamina dinámica y feedback analítico.
- **Motor semanal** — 100 preguntas/área = 10 semanas × 10 preguntas, con simulador temporal.
- **Persistencia** — `localStorage` con capa de funciones puras.

## 🛠 Stack
HTML5 · CSS3 (variables, Grid, Flexbox) · JavaScript Vanilla ES6+ (módulos).
**Cero dependencias externas** (solo tipografías vía Google Fonts).
